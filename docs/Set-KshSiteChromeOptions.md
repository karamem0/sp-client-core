# Set-KshSiteChromeOptions

## SYNOPSIS

```
Set-KshSiteChromeOptions [[-HeaderLayout] <HeaderLayoutType>] [[-HeaderEmphasis] <VariantThemeType>]

 [[-FooterEmphasis] <FooterVariantThemeType>] [[-HideTitleInHeader] <Boolean>]

 [[-HeaderOverlayOpacity] <Int32>] [[-HeaderOverlayGradientDirection] <Int32>]

 [[-HeaderColorIndexInDarkMode] <Int32>] [[-FooterColorIndexInLightMode] <Int32>]
```
